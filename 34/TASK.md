## Семафор для ограничения одновременных Promise

Необходимо реализовать семафор, который ограничивает количество одновременно выполняющихся Promise.

Конструктор должен принимать лимит (максимальное число одновременно выполняемых задач) и Iterable-функций, возвращающих
Promise. Семафор должен быть Iterable, чтобы его можно было использовать с методами Promise.

```typescript
const limitedPromises = new IterSemaphore(2, [f1, f2, f3, f4, f5, f6]);

Promise.all(limitedPromises).then(console.log).catch(console.error);
```

## RWLock (Read-Write Lock)

Необходимо реализовать структуру RWLock, которая управляет доступом к данным с разделением на чтение и запись.

Правила работы:

- **Читатели** (`get()`): могут одновременно читать данные, но не могут их изменять.
- **Писатели** (`getMut()`): имеют исключительный доступ — во время записи никто не может ни читать, ни писать.
- После освобождения блокировки (`free()` или `using`) любой доступ к данным должен выбрасывать исключение.

```typescript
const lock = new RWLock({ value: 1 });

{
  using data = lock.get();
  const { proxy } = data;

  console.log(proxy.value); // 1

  try {
    proxy.value = 2; // ❌ Исключение — запись запрещена
  } catch {}

  try {
    lock.getMut(); // ❌ Исключение — уже есть читающие
  } catch {}

  console.log(proxy.value); // ❌ Исключение — доступ отозван
}

{
  const { proxy, free } = lock.getMut();

  proxy.value += 2;

  console.log(proxy.value); // 3

  try {
    lock.get(); // ❌ Исключение — уже есть пишущий
  } catch {}

  free();
}
```

## Асинхронный семафор

Необходимо реализовать асинхронный семафор, который гарантирует, что переданная функция будет выполнена только один раз,
независимо от того, сколько раз будет вызвана возвращённая функция.

Параметры:

- **Функция** — полезная нагрузка, которая должна быть выполнена один раз.
- **Флаги** — набор строк (или значений), которые используются для идентификации вызова.

Возвращаемое значение:

- Функция, которая принимает флаг и возвращает Promise, резолвящийся результатом выполнения внутренней функции.
- Если внутренняя функция уже была вызвана, повторные вызовы должны возвращать тот же результат.

```typescript
const run = createsAsyncSemaphore(
  () => {
    console.log('Boom!');
    return 121;
  },
  'foo',
  'bar'
);

run('foo').then(console.log); // 121

// Boom! (выводится только один раз)
run('bar').then(console.log); // 121
```
