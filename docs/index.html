Как итератор вытягивает данные

Цепочка ленивая и pull-based: никто не пушит значения заранее. Потребитель зовёт next() у внешнего слоя, запрос идёт вниз, ответ поднимается обратно.

[1…8].values().filter(x > 5).take(2).next()
запрос вниз (.next) значение вверх filter отбросил
consumer
зовёт take.next()
take(2)
взято: 0/2
filter(x > 5)
пропускает только подходящие
values
источник: массив

Один клик «Шаг» = одно событие протокола (вызов next или возврат значения). Чтобы получить один результат consumer, цепочка может сделать несколько таких шагов.
